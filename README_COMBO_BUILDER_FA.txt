InvokerApp 2.0.0 - راهنمای Combo Studio و Overlay
==================================================

این راهنمای نسخهٔ دوم InvokerApp است؛ نسخه‌ای که علاوه بر Overlay، رابط Combo Studio و Combo Assistant را نیز دارد.

قابلیت‌های اضافه‌شده
--------------------
- Combo Studio به‌صورت پنجره مستقل
- برنامه پس از اجرا مستقیماً Combo Studio را در صفحه Home باز می‌کند؛ Overlay تا زمان انتخاب کاربر نمایش داده نمی‌شود.
- دکمه Switch to Overlay Mode در Home برنامه را به Overlay تعاملی می‌برد؛ دکمه COMBO STUDIO روی Overlay برای بازگشت به Studio در دسترس است.
- صفحه‌های Home، Combo Studio، Settings و About در نوار کناری؛ جابه‌جایی بین صفحه‌ها داخل همان پنجره انجام می‌شود.
- هنگام باز بودن Combo Studio، Overlay اصلی موقتاً پنهان می‌شود تا روی Studio یا پنجره‌های تنظیمات نیفتد؛ با بستن Studio دوباره نمایش داده می‌شود.
- ساخت، ویرایش، تغییر نام، حذف و Duplicate کردن Combo
- دسته‌بندی Combo برای Layout 1، Layout 2، Layout 3 یا حالت Shared
- افزودن Spell و امکان تکرار یک Spell در یک Combo
- مرتب‌سازی مراحل با Drag & Drop و دکمه‌های Move Up / Move Down
- ذخیره Comboها در settings.json
- Combo Assistant در پنجره جداگانه
- پنج تم قابل انتخاب برای Studio، Assistant و Overlay: Arcane Premium، Dark Elegance، Modern Gaming، Epic Dota و Minimal Premium؛ Arcane Premium تم پیش‌فرض است. شناسه‌های ذخیره‌شدهٔ تم‌های قبلی بدون تغییر باقی مانده‌اند.
- رابط Arcane Premium از پس‌زمینهٔ زغالی، تأکید بنفش با جزئیات آبی و طلایی، پنل‌ها و دکمه‌های گرد و تصویر پس‌زمینهٔ کم‌رنگِ بستهٔ طراحی استفاده می‌کند. تصویر به‌عنوان تزئین رابط رسم می‌شود و جایگزین کنترل‌ها یا تصاویر واقعی Spellها نیست.
- Combo Studio در نمای اصلی، کتابخانهٔ جست‌وجوپذیر و جزئیات کمبوی انتخاب‌شده را کنار هم نشان می‌دهد؛ Edit Combo فرم ساخت و مرتب‌سازی مراحل را باز می‌کند.
- حالت Manual و Automatic
- Pause / Resume / Previous / Next / Reset / Stop
- میانبرهای ترکیبی و قابل‌تنظیم برای Start، Next و Reset
- نوار پیشرفت و نمایش Spell فعلی و بعدی
- نمایش تصویر Spell از مسیر img، در صورت وجود فایل تصویر
- در Manual Mode (حالت پیش‌فرض)، Start کمبو را آماده می‌کند و هر Next توالی Spell جاری را به پنجرهٔ فعال فعلی می‌فرستد و سپس جلو می‌رود. Automatic Mode نیز توالی هر Spell را خودکار می‌فرستد.
- هنگام فعال بودن پنجره‌های Combo Studio یا Combo Assistant، Hotkeyهای Spell موقتاً از اجرای Sequence جلوگیری می‌کنند تا تایپ نام Combo باعث اجرای Spell نشود.

نصب و شروع سریع
-----------
1. آخرین بستهٔ Windows را از بخش [GitHub Releases](https://github.com/Melonvw/InvokerApp/releases/latest) دریافت و ZIP را Extract کنید.
2. `InvokerApp.exe` را اجرا کنید؛ Combo Studio در صفحه Home باز می‌شود.
3. برای نمایش Overlay، در Home دکمه Switch to Overlay Mode را بزنید. برای برگشت به Studio روی دکمه COMBO STUDIO در Overlay کلیک کنید.
4. از Settings، هاتکی‌های Start، Next و Reset را تنظیم کنید.
5. در Combo Studio یک Combo بسازید و ذخیره کنید.
6. Open Combo Assistant را انتخاب کنید؛ Assistant برای استفاده از هاتکی‌ها در کنار برنامهٔ فعال در دسترس می‌ماند.

Combo Studio هنگام اجرا در صفحه Home باز می‌شود. از صفحه Combo Studio می‌توانید کتابخانه و جزئیات Combo را مدیریت کنید؛ برای مرتب‌کردن مراحل، Edit Combo را انتخاب کنید. Home دکمهٔ Switch to Overlay Mode را دارد. برای مرتب‌کردن مراحل، آیتم را با دکمهٔ چپ ماوس بگیرید و پس از کمی جابه‌جایی روی جای جدید رها کنید؛ دکمه‌های Move Up و Move Down نیز در دسترس هستند.

برای Build سورس در Windows، .NET 8 SDK را نصب کنید و در پوشهٔ پروژه `dotnet build InvokerApp.csproj -c Release` را اجرا کنید. نسخهٔ منتشرشده نیازمند .NET 8 Desktop Runtime است.

نکات مهم
--------
- CapsLock همچنان فقط Layout را عوض می‌کند؛ هیچ QQQ/WWW/EEE اضافی ارسال نمی‌کند.
- F9 در حالت Overlay وارد Edit Mode می‌شود. در این حالت Overlay موقتاً کلیک‌پذیر است؛ دکمه‌های کلید اسپل قابل انتخاب‌اند و با انتخاب کلیدی که به اسپل دیگری اختصاص دارد، کلیدها و جای آن دو اسپل در فهرست Overlay با هم جابه‌جا می‌شوند. با خروج از Edit Mode، وضعیت قبلی کلیک‌پذیری Overlay بازمی‌گردد.
- Insert بیرون از Edit Mode حالت کنترل با ماوس Overlay را تغییر می‌دهد؛ هنگام باز بودن Combo Studio، کلیدهای Overlay روی پنجرهٔ Studio اثر نمی‌گذارند.
- در Manual Mode، Start فقط کمبو را آماده می‌کند؛ با هر Cast + Next یا میانبر Next، توالی Spell فعلی به بازی ارسال می‌شود و فقط پس از ارسال موفق مرحله جلو می‌رود. Reset به مرحلهٔ اول برمی‌گردد و چیزی ارسال نمی‌کند.
- در هر دو حالت، توالی ثبت‌شدهٔ Spell با InvokerController و KeyboardSender به پنجرهٔ فعال فعلی ارسال می‌شود.
- پس از بازکردن Combo Assistant، پنجره‌های Assistant و Studio خودکار Minimize می‌شوند تا جلوی بازی را نگیرند؛ هاتکی‌های سراسری همچنان فعال هستند.
- ارسال کلیدها به پنجرهٔ فعال فعلی انجام می‌شود؛ اگر بازی باز نباشد، برنامهٔ دیگری که فوکوس دارد ورودی را دریافت می‌کند. برای تست، ابتدا یک پنجرهٔ امن و مناسب را فعال کنید.
- برنامه نتیجهٔ Cast داخل بازی را نمی‌تواند تأیید کند؛ فقط ارسال توالی کلید را انجام می‌دهد و دیگر پنجرهٔ بازی را ثبت یا فعال نمی‌کند. برای رفتن به Automatic، حالت را از Assistant تغییر دهید.
- میانبرهای Start، Next و Reset در هر دو حالت قابل تنظیم هستند. پیش‌فرض آن‌ها Ctrl+Alt+S، Ctrl+Alt+Right و Ctrl+Alt+R است. Start از کمبوی انتخاب‌شده شروع می‌کند؛ Next در Manual اسپل فعلی را می‌فرستد و سپس جلو می‌رود؛ Reset کمبوی جاری را از مرحلهٔ اول دوباره فعال می‌کند.
- برای Shared Combo، شناسه Spellها بین Layoutها یکسان‌سازی شده تا Combo در Layout فعال قابل Resolve باشد.
- هنگام باز شدن برنامه، شناسه‌های قدیمی Spellها در settings.json در صورت نیاز به شناسه مشترک تبدیل و ذخیره می‌شوند.
- تنظیمات قدیمی یک‌بار به تم پیش‌فرض Arcane Premium منتقل می‌شوند؛ پس از آن انتخاب تم کاربر حفظ می‌شود.
- فایل InvokerSettings.cs در پروژه اصلی خالی بود؛ کلاس InvokerSettings همچنان در InvokerController.cs نگهداری شده تا ساختار فعلی بی‌دلیل جابه‌جا نشود.
- فایل‌های تصویری Spellها در پوشه img پروژه قرار دارند و هنگام Build به خروجی کپی می‌شوند. اگر تصویری حذف یا خراب باشد، برنامه بدون نمایش هشدارهای تکراری اجرا می‌شود و فقط آیکون آن Spell خالی می‌ماند.
- اگر settings.json قابل‌خواندن نباشد، برنامه آن را با تنظیمات پیش‌فرض جایگزین نمی‌کند؛ پیام خطا نشان داده می‌شود و فایل موجود دست‌نخورده می‌ماند. خطای ذخیره نیز به کاربر اعلام می‌شود.

Build و تست
-----------
برای Build روی ویندوز، فایل InvokerApp.csproj را در Visual Studio با .NET 8 باز کنید و Build > Rebuild Solution را اجرا کنید؛ یا از پوشه پروژه دستور `dotnet build InvokerApp.csproj` را اجرا کنید.

سورس کامل پروژه در مخزن GitHub و بستهٔ اجرایی هر نسخه در بخش Releases منتشر می‌شود. تنظیمات در `settings.json` کنار فایل اجرایی ذخیره می‌شوند؛ هنگام به‌روزرسانی، این فایل را برای حفظ Layoutها و Comboها نگه دارید.
